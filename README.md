# 鼠标脚本工具

一款界面参照"全方位鼠标连点器(360专版)"的轻量自动化小工具：**脚本编辑窗口点"添加"弹框填参数**就能做脚本，也支持**纯文本脚本**在记事本/Word 里改好直接识别。脚本名称支持**红色/绿色标记**区分账号和密码，双击即复制、按 F10 自动打字输入。卡密激活后使用。

> 作者：西塔（ptyo7o2）  ·  当前版本：v1.1（2026-10-31）

## 功能特性

- **脚本编辑窗口**（照参考软件交互）：左侧操作列表（鼠标移动到 / 等待 / 左键点击 / 右键点击 / 按下 / 松开 / 双击 / 中键 / 输入文字）逐项"添加"，弹出参数对话框（确定/取消），动作展现在右侧表格（序号/动作/参数，每行可 📄 复制、🗑 删除），"保存鼠标宏"存成文本脚本自动进主列表
- **选取坐标**：弹框里点"选取坐标"，屏幕出准星遮罩，鼠标移到哪实时显示坐标，单击取位自动填入 X/Y
- **执行次数 0~99（默认一次）**：点击、输入文字对话框都带
- **纯文本脚本**：6 条指令（`移到` / `点击` / `等待` / `输入` / `按下 ctrl` / `松开 ctrl`），记事本、Word 都能编辑
- **兼容 .qfwjb**：旧版"全方位鼠标连点器"的录制文件直接导入运行，无需转换
- **红/绿颜色标记**：脚本名称一键标记 红色(账号) / 绿色(密码) / 默认黑，颜色持久保存
- **重命名**：右键改名，列表和文件一起改
- **双击复制**：双击脚本名，把脚本里"输入"的内容复制到剪贴板，Ctrl+V 即粘贴
- **F10 运行/停止**：全局热键，运行中再按一次 F10 停止；**快速连按 3 次 Esc 强制退出软件**
- **回放次数**：自定义次数（1~9999）或无限循环
- **卡密验证**：首次激活绑定机器码，支持短时离线使用

## 脚本格式

UTF-8 纯文本，一行一个指令，`#` 开头为注释：

| 指令 | 说明 |
| --- | --- |
| `移到 134,87` | 鼠标移动到屏幕坐标 |
| `左键点击` / `右键点击` / `中键点击` / `左键双击` | 点击 |
| `左键按下` / `左键松开`（右键/中键同理） | 按住/抬起，可组合拖拽 |
| `按下 ctrl` / `松开 ctrl`（另有 shift / alt / win） | 修饰键 |
| `等待 200` | 等 200 毫秒（1000 毫秒 = 1 秒） |
| `输入 你要打的文字` | 一次输入整串文字，支持中文 |
| `# 注释` / 空行 | 忽略 |

示例（账号脚本，标红色）：

```
# 登录账号
移到 317,233
左键点击
等待 200
输入 zhangsan123
```

`.qfwjb` 兼容：`鼠标移动到：x,y`、`鼠标左键按下：0,0`、`ms200`、`键盘NumPad1键按下：75` 等录制格式全部识别。

## 使用步骤

1. 双击 `鼠标脚本工具.exe`，首次启动输入卡密激活
2. 按 **F9** 打开脚本编辑窗口，点左侧"添加"逐步做脚本（或点"选取坐标"取坐标），保存后自动进列表
3. 右键脚本名 → **颜色**，红色标账号、绿色标密码
4. 把光标点进目标程序的输入框
5. 勾选脚本 ☑ → 填回放次数 → 按 **F10**；或**双击脚本名**复制后手动粘贴
6. 想停：再按 F10；紧急情况：快速连按 3 次 Esc 强制退出

## 热键

| 热键 | 作用 |
| --- | --- |
| F9 | 打开脚本编辑窗口（全局热键） |
| F10 | 运行勾选的脚本；**运行中再按一次 = 停止**（全局热键） |
| Esc ×3 | 约 1.5 秒内快速连按 3 次 = 强制退出整个软件（只观察不拦截，不影响其他软件的 Esc） |

## 卡密说明

- 卡密格式 `AG-2D-XXXXXXXX`，首次激活绑定电脑（Windows MachineGuid），一台卡一台机
- 服务端短期不可达时自动进入离线模式（沿用上次验证结果），联网后恢复
- 换机/重装系统需联系作者解绑

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 卡密不存在 | 核对大小写与首尾空格 |
| 已绑定其他设备 | 联系作者解绑 |
| F10 没反应 | 确认已勾选 ☑ 且光标已点进目标输入框；管理员权限的窗口需以相同权限运行本工具 |
| 中文输入乱码/丢字 | 先点一下输入框获得焦点，脚本里加 `等待 200` 放慢 |
| 修改脚本没生效 | 编辑器点"保存鼠标宏"立即生效；记事本改完保存文件即可（每次运行重新读取） |
| 闪退 | 确认 64 位 Win10/11，杀毒软件加信任 |
| qfwjb 小键盘数字不对 | NumLock 状态录制和回放保持一致 |

## 注意事项

- 脚本是**明文**保存账号密码的，带密码的脚本文件请勿外传
- F9/F10 为全局热键，本软件运行时占用这两个键，不需要时请退出软件

## 项目结构

```
main.py            主程序（tkinter 界面、列表、热键、运行线程、重命名）
editor.py          脚本编辑窗口（添加动作、参数弹框、选取坐标、试运行）
scriptfmt.py       脚本解析与序列化（简单格式 + qfwjb 兼容 + 编辑器互转）
sim.py             Windows 输入模拟（SendInput、全局热键、Esc 连按钩子、执行器）
license_client.py  卡密验证客户端（HMAC 签名校验、离线容错）
build.ps1          一键打包脚本
HANDOFF.md         需求交接与卡密清单（本地留存）
```
