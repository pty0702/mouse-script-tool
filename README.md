# 鼠标脚本工具

一个界面参照"全方位鼠标连点器(360专版)"的小工具：**脚本就是普通文本文件**，在记事本或 Word 里改好、另存为 `.txt`，导入即可运行。脚本名称可以用**红色/绿色**区分账号和密码，双击即复制、按 F10 自动输入。

## 功能

- **导入脚本**：支持 `.txt`（简单格式），也兼容"全方位鼠标连点器"导出的 `.qfwjb` 录制文件
- **红/绿颜色区分**：右键脚本 → 颜色 → 红色(账号) / 绿色(密码) / 默认黑，颜色记住、重启不丢
- **双击脚本名**：把脚本里"输入"的内容复制到剪贴板，去输入框 Ctrl+V 即可
- **F10 运行**：把光标点进目标输入框后按 F10，工具自动把内容逐字打进去（支持中文）
- **回放次数**：自定义次数，或"无限循环"（用 F11 停止）
- **F9 新建脚本**：自动生成模板并用编辑器打开，改完保存再导入

## 脚本格式（.txt，UTF-8）

| 指令 | 说明 |
| --- | --- |
| `移到 134,87` | 鼠标移动到屏幕坐标（可选） |
| `左键点击` / `右键点击` / `左键双击` | 点击（可选） |
| `等待 200` | 等 200 毫秒 |
| `输入 你的账号abc` | 一次输入整串文字，支持中文 |
| `#` 开头 | 注释行；空行忽略 |

示例（账号脚本）：

```
# 红色=账号
移到 317,233
左键点击
等待 200
输入 zhangsan123
```

旧的 `.qfwjb` 文件（`鼠标移动到：x,y` / `ms200` / `键盘NumPad1键按下：75` 这类）直接导入也能识别运行。

## 热键

| 热键 | 作用 |
| --- | --- |
| F9 | 新建脚本模板（在程序旁"脚本"文件夹生成并打开） |
| F10 | 运行勾选的脚本（全局热键，切到别的窗口也能按） |
| F11 | 停止运行 |

## 使用步骤

1. 双击 `鼠标脚本工具.exe`
2. 点 **导入**，选择 `.txt` 或 `.qfwjb` 脚本（可多选）
3. 右键脚本名 → **颜色**，红色标账号、绿色标密码
4. 把光标点进目标程序的输入框
5. 勾选脚本 → 填回放次数 → 按 **F10**；或者**双击脚本名**复制内容后手动 Ctrl+V

## 注意事项

- 脚本里是**明文保存**的账号密码，请别把脚本文件发给别人
- `.qfwjb` 的小键盘数字依赖 NumLock 开关状态，录制时开着回放时也要开着
- 双击"复制"取的是脚本里所有 `输入` 行的内容；没有输入行时复制整份脚本文本
- 配置（列表、颜色、次数）保存在程序同目录 `config.json`

## 开发与打包

依赖：Python 3.10+（仅标准库，无第三方依赖）。

```powershell
# 打包成单文件 exe
pwsh -NoProfile -File build.ps1
# 产物在 dist\鼠标脚本工具.exe
```
